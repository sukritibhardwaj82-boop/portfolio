Commands you'll actually use.

Most of what you'll ever do with git is these eleven lines.

$ Terminal 
git config --global user.name "Your Name"   # tell git who you are
git clone <repo-url>                        # copy a repo to your laptop
git status                                  # what changed?
git add .                                   # stage every change
git commit -m "say what you did"            # save a snapshot
git push                                    # send your commits to GitHub
git pull                                    # get the latest from GitHub
git switch -c <branch-name>                 # make a branch and move to it
git switch main                             # go back to main
git merge <branch-name>                     # bring a branch into this one
git log --oneline                           # history, one line each
